# 当前身份与权限

本表对应 2026-11-16 的权限对齐版本，范围是单个机构的四个校区。网页人脸签到在启用该功能的环境中可用。家长服务号和教学反馈发送仍待开发。

任课教师可在上课当天开课后为本节课应到且未签到的学生逐一核验。首次录入须核对学生本人并填写监护人授权凭证。已有档案由有权限的校区管理员管理。

绩效明细仅包含教师、班级、授课日期、时长、实到人数、费率、应付金额及审核状态，不包含学生个人档案、家长联系方式、人脸档案、学生余额和续费收入。

## 兼任身份

老板可给已有教师分配或撤销管理权限，保留其教师角色、密码、常驻校区及任课关系。教师常驻校区与管理校区可不同。进入教师工作台按本人任课和代课授权，进入管理工作台仅按管理校区授权。权限变更撤销旧会话，重新登录生效。兼任管理身份的教师账号只能由老板停用或重置密码。

## 课时与财务边界

- 原教师余额调整入口已撤除，教师访问老板调整接口也会被拒绝。
- 调课时申请记录原余额、版本、目标余额、原因和校区，仅老板能批准或拒绝。批准、改余额、写流水和审计在同一事务提交。
- 等待审批期间若发生续费、签到或其他调整，旧申请不得覆盖新余额，需拒绝后重新核对。重试申请和直接调整不会重复入账。
- 续费记录收费校区。学生之后换班不会把这笔收入转给另一校区；有多个收费校区时，老板须明确选择。
- 周报按课次校区过滤，招新按报名班级校区过滤，续费按交易收费校区过滤。汇总与明细范围一致。
- 全机构历史报表快照仅老板可访问，校区管理员不能通过历史版本地址读取。
- 新增 runtime-permissions-v2 迁移，增加续费校区归属及课时调整申请表，不修改已经清空的学生和账号。

## 验收范围

自动验证使用虚构资料，覆盖跨校区读写、改变校区后重试旧命令、教师兼任与撤权、审批并发和失败回滚、余额变化后审批、老板复核及手机操作。真实数据核验只读，不创建测试学生或教师账号。
