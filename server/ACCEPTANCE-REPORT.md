# 统一运行本机端到端验收报告

验收日期：2026-11-07
范围：虚构数据、临时 PostgreSQL、FastAPI ASGI 接口、真实备份与独立恢复
结果：**本机链路通过；不是生产上线完成证明**

## 一、执行链路

1. 建立 `runtime_rehearsal_acceptance_source` 和 `runtime_rehearsal_acceptance_restored` 两个临时数据库。
2. 在源库初始化 `fresh-start-runtime-v1`，写入两名虚构学生、两个班级、教师、管理员、设备和课堂。
3. 通过正式 API 依次执行管理员续费与开课、平板名单读取与签到、教师请假、平板离线冲突归档、双方周报及管理员月报。
4. 核对源库事件、课时流水、幂等回执和余额，再执行 PostgreSQL 自定义格式备份。
5. 将备份恢复到独立空库，逐表比对规范化摘要，并重新执行健康检查、管理员会话和全校周报。

复现命令（在 `server` 目录及测试虚拟环境中）：

```bash
python -m unittest tests.test_runtime_acceptance
```

## 三、与其他证据的关系

- 本链路使用 FastAPI TestClient 调用正式 ASGI 应用和真实临时 PostgreSQL，不把它描述成真实公网请求。
- 真实 Uvicorn 子进程启动、停止、原端口重启、端口占用和数据库中断由 `tests.test_runtime_service_hosting` 单独覆盖。
- 发布包隔离解压及正式 ASGI 入口由 `tests.test_runtime_release_package` 覆盖。
- 浏览器页面、人脸组件和窄屏验收结果见开发日志中各对应节点；本报告不替代真实摄像头、真实平板或 Linux／systemd 验收。
