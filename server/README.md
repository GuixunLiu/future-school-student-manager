以下仅在独立开发环境执行，不在已有项目的系统 Python 中安装包：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover -s tests -v
```

Windows 将 `.venv/bin/python` 替换为 `.venv/Scripts/python.exe`。本次本地运行环境为 Python 3.12；Dockerfile 目标为 Python 3.11，远程 Linux/Compose 构建尚未执行，不据本地通过宣称容器已部署。

只运行基础服务时，在 `app/` 目录执行：

```bash
../.venv/bin/python -m uvicorn wxnotify_api:app --host 127.0.0.1 --port 18080 --no-access-log --no-proxy-headers
```
