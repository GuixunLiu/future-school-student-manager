# 统一运行系统上线核对清单

本清单对应 `future-school-unified-runtime-release-v1` 候选包。候选包只包含代码、固定依赖说明、网页资源、人脸组件和本机演练工具，不包含真实业务数据、账号密码、设备令牌、人脸密钥或微信密钥。

## 当前边界

- 本包是内部上线候选，不代表生产验收完成；`/health/ready` 会继续返回 `production_ready=false`。
- 当前访问守卫只接受服务器回环客户端及 `localhost／127.0.0.1／[::1]` Host。先使用 SSH 隧道验收，不要直接开放公网端口。
- 域名和 HTTPS 尚未完成前，不切换为公网教师入口。不得通过关闭权限或 Host／Origin 检查绕过限制。
- 微信发送保持关闭，家长绑定和真实推送不在本次上线范围。
- 生产发布、真实数据迁移和真实平板切换需要另行明确授权；本机演练工具没有生产应用模式。

## 一、发布包核验

- [ ] 从构建回执记录 ZIP 文件字节数和 SHA-256，传输后在目标机重新计算并保持一致。
- [ ] 校验 `MANIFEST.json`：格式、运行入口 `management.runtime_main:app`、数据库结构 `fresh-start-runtime-v1`。
- [ ] 确认清单声明不含业务数据、不含凭据、微信关闭、非生产完成版。
- [ ] 解压到全新版本目录，不覆盖旧版本；逐个核对包内文件摘要，拒绝重复路径或 `..` 路径。
- [ ] 不使用旧 `package-management-release.py`、旧 SQLite 发布包或旧七文件基础包替代本候选包。

## 二、目标机只读预检

- [ ] 确认目标 Python 与依赖兼容；在独立虚拟环境安装 `requirements-runtime.txt`，不修改共用系统 Python。
- [ ] 核对 PostgreSQL 可连接、磁盘空间、备份空间和数据库账号最小权限。
- [ ] 核对新服务使用独立回环端口，端口未被占用，不停止或替换旧服务。
- [ ] 检查服务目录权限和私有环境文件权限；环境变量只提供 `RUNTIME_DATABASE_DSN`，需要人脸时另行安全提供 `FACE_PROFILE_KEY`。
- [ ] 不在命令行、日志、MANIFEST 或公开回执中记录数据库密码、人脸密钥和令牌。
- [ ] 确认运行进程只绑定 `127.0.0.1`，关闭代理头信任、WebSocket 和访问日志中的敏感信息记录。
- [ ] 在目标机解压目录运行 `python -B ops/runtime-preflight.py --runtime-root <版本目录绝对路径> --python <虚拟环境Python绝对路径> --environment-file <私有环境文件绝对路径> --port <候选端口>`。脚本只读检查 Linux、Python、固定依赖、磁盘、端口和权限，不安装软件、不修改文件或服务。
- [ ] 私有环境文件不得是符号链接，属主须为 root 或当前用户，组及其他用户权限必须为 0。预检不读取该文件内容，不回显环境变量、DSN 或数据库异常原文。
- [ ] 如需数据库连通性检查，先通过目标机私有会话注入 `RUNTIME_DATABASE_DSN`，再增加 `--database`；不得把 DSN 放在命令行。该项仅执行 `BEGIN READ ONLY`、`SELECT 1` 和回滚，不读取或写入业务表。
- [ ] 预检通过只代表当时的基础条件满足，端口启动前仍须复核；任何失败项先停止，不用跳过检查代替修复。

## 三、备份与迁移停止点

- [ ] 在真实操作前另做一致性备份，并实际恢复到独立数据库核对；只有备份文件存在不等于恢复通过。
- [ ] 记录备份时间、摘要、恢复位置和业务停止窗口；备份期间若源库变化，重新执行核对。
- [ ] 当前已验证的是虚构资料全新迁移，不是旧真实业务库自动升级。不得把 `runtime_release.py` 指向生产库。
- [ ] 若选择舍弃旧业务数据，须由负责人再次确认范围；教师账号、初始管理员和课程资料按确认后的初始化方案另行创建。
- [ ] 若需要保留旧业务数据，先补充专门生产迁移方案和真实副本验收；未完成前停止，不用空库冒充迁移成功。

## 四、隔离启动与健康检查

在新版本目录设置私有服务环境后，使用独立虚拟环境启动一个工作进程：

```bash
python -m uvicorn management.runtime_main:app \
  --host 127.0.0.1 --port 18090 --workers 1 \
  --no-proxy-headers --no-server-header --no-access-log \
  --no-use-colors --ws none --limit-concurrency 32 \
  --timeout-keep-alive 5 --timeout-graceful-shutdown 10
```

- [ ] 需要 systemd 托管时，按 `ISOLATED-LAUNCH-RUNBOOK.md` 使用 `ops/render-runtime-service.py` 渲染包内候选模板。只传入版本目录、Python、私有环境文件绝对路径和端口；输出必须是新的 `.service` 文件，不接收或写入密码、密钥。
- [ ] 审阅渲染结果，不得留下任何占位符；生成回执只代表本地文件已生成，`installed=false`、`started=false`，不代表目标机已安装或启动。
- [ ] 模板使用动态低权限用户、一个 Uvicorn 工作进程和回环地址，限制重启频率、内存、CPU 和任务数。安装前按目标机策略复核；执行 `systemd-analyze verify` 后再加载。Windows 本机测试不能代替 Linux／systemd 实测。
- [ ] 启动失败时保留错误，不删除旧服务、不回滚覆盖新业务；模板仅在失败时有限重试，连续失败须停止并排查。
- [ ] 请求 `/health/ready`，确认 `status=ready`、`initialized=true`、结构版本正确。
- [ ] 确认 `production_ready=false`、`wechat_sending_enabled=false`；不得为了让检查变绿而修改标记。
- [ ] 通过 SSH 隧道打开 `/runtime`，检查登录、教师课堂、管理员课表、续费、报表和人脸档案入口。
- [ ] 核对非授权教师、跨班访问、重复请求、取消课次和断网冲突处理。
- [ ] 缺少 `RUNTIME_DATABASE_DSN` 时必须拒绝启动且不开放端口；端口已被占用时必须退出，不得停止或替换已有监听者。
- [ ] 数据库中断时写操作返回 `503 storage_unavailable`，不得向平板返回成功。恢复数据库并核对私有连接配置后，使用原签到编号重试，再核对事件、流水和余额，确认故障请求没有留下部分写入。

## 五、真实平板切换前验收

- [ ] 先保留每台平板当前完整备份和原 APK，记录版本及设备授权范围。
- [ ] 使用隔离测试包，先验证 1920×1080 横屏、摄像头、人脸、断网续传和重启恢复。
- [ ] 验证丢回执重试只扣一次，网页补签／请假后平板归档不再次扣课。
- [ ] 验证取消课次、余额变化、人脸档案下载失败和安全换绑均保留本机证据。
- [ ] 不卸载旧 App、不清数据、不重放历史签到；未完成前不切换日常设备。

## 六、回滚与完成判定

- [ ] 应用回滚只切回经核验的旧代码和旧服务；数据库回滚不得覆盖切换后已经产生的新业务。
- [ ] 如需数据库恢复，先停止写入并保存当前状态，再由负责人选择恢复时点；禁止直接用旧备份覆盖新数据。
- [ ] 记录发布、健康、权限、平板和恢复验收结果；任何一项未完成均不得写成正式上线完成。
- [ ] 微信端等待域名、HTTPS 和备案完成后单独开发验收，不随本包启用。
