# wxnotify v0.4.0 工作台与平板事件（隔离联调）

2026-10-25。在v0.3.0工作台上增加明确授权的平板新事件接口与设备管理。它与远程v0.1.0基础健康服务分开，**尚未上传、安装或切换远程服务**；本轮没有重新连接远程检查其运行状态。安卓v4.10.0已完成隔离实机联调，并覆盖更新日常应用，同步默认关闭；未读取或上传日常学生资料。74项服务器测试及网页设备注册/授权/轮换验收通过。

## 已完成的范围

| 业务 | 当前实现 |

本地测试家长关系只能通过 `/v1/test/parent-links` 由管理员创建；这不是微信关注、网页授权或真实监护关系核验。不得给真实家长开此入口。教师和管理员可以兼任，分别收到所启用身份的消息；教师周报仍限本人及当前获授权班级，管理员全校范围不替代教师身份范围。

## 独立启动

需要 Python 3.11 或以上，运行命令时位于解压后包根目录（含 `business/` 和 `app/`）。本轮实际测试使用 Windows Python 3.12，尚未进行 Linux/容器部署验收。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r app/requirements.txt
.venv/bin/python -m business.cli bootstrap --database /ABSOLUTE/PRIVATE/DIRECTORY/pilot.sqlite --organization school-test --login owner-test --display-name TestOwner
.venv/bin/python -m business.cli serve --database /ABSOLUTE/PRIVATE/DIRECTORY/pilot.sqlite --local-test --port 18081
```

Windows 使用 `.venv/Scripts/python.exe`，数据库路径换为本人的绝对私有路径。初始化提示输入两次密码，15–128字符，无默认账号密码；不把密码写进命令、聊天或发布包。已存在的文件一律拒绝初始化或覆盖，无匿名网页初始化入口。登录需使用初始化时的机构名、账号和密码。

启动后，在本机浏览器打开 `http://127.0.0.1:18081/` 即是工作台。网页及样式、脚本全部在包内，无CDN、广告、外部字体或统计脚本。用户登录令牌只留在当前页面内存，不写浏览器本地存储或Cookie；刷新需要重新登录。退出会立即清空当前页面的资料，旧请求晚返回不会重新显示旧账号资料。不同域名或来源的页面不能访问本服务，不能将它直接挂到公网代理。

### 页面使用顺序

1. 管理员在“人员与身份”创建老师或管理员，可以同时勾选两种身份。在“班级与任课”创建所属课程和完整班名，再指定已有教师身份的任课老师；旧页面遇到并发权限变更会拒绝覆盖，需刷新核对。
2. “学生名册”用于查看和录入独立联调资料，显示核对编号以区分重名。录入不会从平板导入，也不会自动计为新生业务或改变平板课时。当前页面没有人脸资料、平板整库上传或手动微信绑定入口。
3. 管理员在“课堂”选择实际日期安排一次课；自动保存当前在用学生名单。隔周班只安排实际课日，不自动创建休课周。新安排不扣课时或补造签到。
4. 老师进入课堂查看未到与请假名单，按学生编号核对后办理请假/撤销，或选择仍未到学生并确认家长提醒演练。课堂内容可提前编辑，默认只保存草稿，可选择实际到课或全部应到家长，另行勾选课后通知演练。保存失败保留文字；有未保存内容时先保存再办理请假，避免刷新覆盖草稿。
5. 管理员看全校周/月报告；兼任老师时可切换“我的任课报告”，教师身份范围仍由服务器独立校验。月报可登记明确的新生/续费业务，记录本身不改课时、不证明资金到账。
6. 在“通知设置”确认本人接收选择；管理员可以保存演练时间和阈值，再手动生成/处理到期演练。“通知记录”明确区分待演练、已演练、取消及过期，不显示虚假的发送成功。

工作台已用独立虚构资料在桌面、平板横向/竖向及390像素手机宽度验证；宽表格可在表格区域左右查看，页面本身不横向溢出。家长服务号页面、真实微信绑定、平板联网和远程部署仍未接通。

只监听 `127.0.0.1:18081`，拒绝非回环来源，忽略代理来源头，不启用 CORS，不打印访问日志。不要将该测试服务挂到公网代理或开放防火墙端口。`--local-test` 必填，开启微信/平板同步/真实绑定环境变量时拒绝启动。健康返回 `mode=local_test`、`business_ready=false`，模拟接口可用不代表已上线。

密码保存为有随机盐的 PBKDF2-SHA256（600,000次）验证值；令牌只存摘要，用户会话8小时、最多5个，设备90天，可随时撤销/轮换。连续登录失败受账号及来源限流保护。每次请求重新验证当前身份和范围；撤销身份同时使旧会话失效。管理员重置密码后需要重新登录，不提供密码找回后门。

Linux 新数据库和备份请求0600权限、私有目录0700；Windows 还需由所在用户目录的访问控制保护。数据库和备份含身份验证值及业务资料，不是加密文件，不能加入 Git、交付ZIP、共享盘公开目录或聊天附件。

## 统计与通知时间

- 固定使用中国时间（UTC+08:00）；所有输入时间必须带明确时区。课时以整数百分之一为单位：150表示1.5课时。允许负课时；服务器保存来源快照，不重复扣减。余额版本只接受较新版本；首次来源绑定后其他设备不能覆盖。换设备迁移流程尚未实现。
- 一次课保存独立日期、开始/结束时间、任课老师和确认名单。后加入学生不反向增加旧课应到；本版不自动生成周期排课，也不自动导入平板历史在读/转班资料。隔周课按实际日期创建两次课，中间没有课次即不计应到。
- 到课率按总实到人次÷总应到人次，含请假；8/10=80%，再加1/2后为9/12=75%。整节请假仍是0%，无课分母为0时返回 `null`。周报只汇总已结束且已确认课次，注明范围，未结束课次单列。请假与未到名单分开显示。
- 周报发送时间可配置星期、时分，默认周日21:00，**这只是待确认的测试默认值**。生成时等待该周最后一节已登记课程结束；同周新增/更正课程后的重报策略尚未实现。日常作业与周报默认关闭，不会自行定时运行；仅管理员手动调用 `jobs/tick`。
- 月报按完整自然月统计，月末结束后次月1日00:00起可生成，可再延迟0–1440分钟；避免月末当天尚未结束就漏统计。新生人数、续费人数、续费笔数分开。仅统计明确登记的新生/续费事件，不从余额增加猜测续费，无财务金额或自动加课时功能。
- 通知接收选择默认关闭；定时作业开关默认关闭，课堂内容还需明确选择课后发布。打开开关、增加绑定或登记接收意向不会自动补发之前的事件。家长未到通知必须由老师再次选择确认；5分钟提醒首先给老师。
- 实时事件、补签、历史导入分开；补签及历史导入不生成通知，超过24小时的实时事件也不补发。排队通知24小时过期，模拟前重新检查身份、授权、绑定、接收选择及相关请假/签到事实。生成后才请假或签到的过时未到提醒会取消。撤销签到不谎称撤回已模拟通知，也不自动退款。
- 待模拟最多2000条、单次模拟最多200条；队列满会累计跳过次数，签到仍成功。单课名单最多500人；周报最多1000课次和5000应到人次，月报5000事件，超出时明确报错，不静默生成完整统计的假象。消息仅包含有限摘要，完整报告需经过权限校验查看。

## 备份与恢复演练

```bash
.venv/bin/python -m business.cli backup --database /ABSOLUTE/PRIVATE/DIRECTORY/pilot.sqlite --output /ABSOLUTE/PRIVATE/DIRECTORY/pilot-backup-unique.sqlite
```

使用 SQLite 一致性备份，不直接复制正在写入的数据库；仅新建目标，校验完整性并输出SHA-256。失败目标应单独标记无效，不覆盖重试。演练恢复时，在另一个新的私有目录放备份副本，用同一版本和另一个空闲回环端口启动，核对身份、课堂、余额与审计后结束演练；不得用未核对备份替换运行中数据库。当前没有自动生产恢复、自动迁移或远程备份清理脚本。
