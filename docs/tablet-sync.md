# 平板新事件同步（v4.10.0 / 服务器v0.4.0）

2026-10-25。核心签到继续在平板离线办理。此版本增加可选的新事件上传，默认关闭，不因为安装更新就迁移学生或发送消息。本轮已用独立调试应用和虚构资料完成连接平板的真实原生通信测试；远程业务服务、真实名册迁移和微信尚未启用。

## 接通前的核对

1. 在独立业务服务建立机构、管理员、课程、班级和名册。服务器学生核对编号必须等于平板学号，姓名、完整班级名、当前余额也必须一致。先做迁移及余额核对，不能用重名或相似名称猜配。当前没有自动全量迁移按钮。
2. 在网页“平板设备”注册设备并限定班级，私下保存仅显示一次的设备凭证。注册本身不启用同步；明确授予新事件同步权限，若需同步老师在平板代办的请假，再额外委托该能力。
3. 在服务器按实际日期确认课次和当次名单，包括隔周课、调课与加课。计划窗口为过去14天至未来31天；没有对应实际课次、转班后不匹配或范围外补签，会显示需核对，不自动补建课堂。
4. 正式服务提供可用HTTPS地址后，在平板后台设置打开同步管理，通过安卓配置窗口输入服务地址和此设备凭证。输入框不在网页中，凭证不传回网页。正式包不接受明文HTTP；本轮USB回环仅用于独立调试包。
5. 刷新核对名单并预览。确认学号、姓名、班级、起始余额、设备和课次后明确启用；不匹配学生不会默默加入。既有历史签到、请假和课时流水不补传。启用前发生的操作必须另行核对，不能假定服务器已有。

同一机构/学生已有另一设备的余额来源时拒绝接管，需管理员先处理来源归属。设备凭证轮换后，重新配置同一设备并核对原映射才能继续；未处理待办不能改投另一设备或机构。

## 数据与通知

| 本机事件 | 服务器行为 |
| --- | --- |
| 新签到 | 按精确学生和真实课次保存事件及余额快照；不再次扣课 |
| 补签 | 保存补签来源；日期型补签的实际时刻保持未知，不伪造历史通知 |
| 增课、余额调整 | 保存版本化余额快照；不能据此自动认定新生或续费交易 |
| 撤销签到 | 幂等撤销自己的已同步事件，再保存本机最终余额；不声称撤回已发消息 |
| 本机代办请假/撤假 | 仅在设备获额外委托后同步，留痕标明设备及未核验办理姓名；不冒充独立教师登录 |

只有最小标识、课次、事件、余额和必要办理说明进入请求，人脸、照片、联系人、全量备份不上传。服务器当前通知仍是模拟；真实关注/授权/家长关系、OpenID、模板字段、发送回调和接收选择需要单独接通与验收。

这不是双向同步。新增学生、转班、排课、教师变更、服务器网页办理的请假及冲突，不会自动下载合并到平板。暂时不要同时在两端改同一学生事实；出现409等冲突需核对后处理，不能反复强制覆盖。服务器报表只代表已登记课次和已接收事实，未迁移历史时不能当成完整全校历史。

## 断网、暂停和恢复

本地业务与新待办同次写入；保存失败一起回滚。发送后的内容固定，同一学生按顺序处理，其他学生可以独立继续。服务器已保存但回执丢失时用同一事件重试，不再次扣课。只在回执中设备、事件和类型均匹配后完成待办。

失败退避约5秒至5分钟，在应用打开时自动处理，也可手动重试；应用完全关闭时没有常驻发送服务，下次打开恢复。暂停提交仍记录后续待办。401/403暂停并保留记录；其他业务冲突需核对，不标记假成功。队列上限2000条，收据映射上限5000条，超限显示未同步计数，本机签到不受阻；不能忽略计数后声称全部已同步。计划最多2000名学生、500课次、10000名册关系，超出明确报错。

恢复完整备份会移除其中同步状态、映射和待办，避免重放；重新核对前不提交。安卓私有凭证不在JSON中，卸载/清除数据会丢失，不用此方式解决配置问题。同步失败时优先保留现有资料及日志，检查当前授权和待办，不重新签到或重复充值。

## 本轮证据与边界

独立调试包使用`.synctest`包名及独立备份目录，真实设备测试验证了原生配置、凭证加密后重启可用、启用不重放旧记录、USB断线待办、服务端提交后回执丢失、重启原样重试、撤销返课快照、代办请假/撤假、撤权后停止提交。截图仅虚构资料：[平板隔离联调](screenshots/tablet-device-sync.png)。未读取日常应用学生数据库、未上传真实学生或修改远程服务。

正式APK增加INTERNET普通权限，但默认无地址、无凭证、无启用映射。保留原应用签名和数据目录覆盖更新，正式构建关闭网页调试，网络配置仅信任系统证书且不允许明文连接。本轮设备测试不代替未来正式HTTPS、真实数据迁移和微信完整验收。

实现参考：[Android网络安全配置](https://developer.android.com/privacy-and-security/security-config)、[Android Keystore](https://developer.android.com/privacy-and-security/keystore)、[WebView原生桥风险](https://developer.android.com/privacy-and-security/risks/insecure-webview-native-bridges)。不声称当前平板密钥具有硬件级保障。
