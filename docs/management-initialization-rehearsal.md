# 整库初始化隔离演练（2026-11-02）

本轮已实现可运行的整库初始化器：用 SQLite backup 从真实完整数据库制作一个新的独立副本，在副本内建立规范期初和不可变历史。它不是从只读名册重建账号，也不在原工作库执行更新。候选管理 API 明确拒绝启动标记为 `rehearsal_only` 的库。

## 已实现的行为

- 复制全部旧表，包括密码哈希、会话、设备凭证、旧补签申请、镜像及不认识的私有表。全部原表逐表摘要核对；只有草案指定的基础学生状态/余额/当前班级和当前班任课关系允许变化。
- 522个已有身份沿用；138已有归档保持原行，21已停课基础学生只停用、不搬表、不删ID。3个预留ID只在副本建立基础行，不生成新生或续费事件。服务器独有的学生和班级保留。
- 在读学生当前余额建立为 revision=0 的期初；旧签到和扣课不重放。历史原文件逐字节存入，另保存每分区必要原始行，包含72条未展开的旧班签到，不创造替代课次。
- 期初、历史行、来源映射、初始化记录及封存凭据禁止改删；封存后禁止追加该批历史。初始化一个机构只能有一次。新设备授权、规范签到、交付队列均为空。
- 只接受严格摘要一致的草案/历史/来源核对；复制后重新导出并比较当前资料，余额、姓名、任课、镜像版本等已变则停止。原表更新及新表建立在一个事务中；触发器改写新身份、破坏其他表或注入事件均停止并清理本次副本。
- 输出必须是新的绝对私有 Linux 目录，拒绝符号链接、原目录覆盖及 Git 内输出。数据库、输入和父目录必须由当前用户拥有且不向其他用户开放。数据库复制有30秒限制；输入有界，副本摘要流式计算。

## 可执行代码包

打包器只有明确白名单的18个源码/说明文件及一份摘要清单，不带学生资料、数据库、密码、虚拟环境或服务安装器。使用 Python 标准库，不需要安装新依赖。

在仓库根目录生成到仓库外：

```powershell
python server/ops/package-management-rehearsal.py --output C:/private/rehearsal-code.zip
```

先核对代码包外部SHA256，再在服务器一个新的私有目录中解压，逐项核对 `MANIFEST.json`。准备**同一轮已核对**的草案、历史和来源核对文件；文件0600、目录0700。只演练的命令如下，其中路径和草案摘要必须替换为该轮实际值：

```sh
python3 server/ops/rehearse-management-initialization.py \
  --source /private/current/business.sqlite \
  --output-dir /private/new-rehearsal \
  --plan /private/inputs/plan.private.json \
  --plan-sha256 <本轮明确核对的64位摘要> \
  --archive /private/inputs/history.private.json \
  --review /private/inputs/review.private.json
```

成功后只产生 `rehearsal.sqlite` 和 `receipt.private.json`，终端只打印范围、保留结果和摘要。完整副本和回执有私有资料及凭证，留在服务器私有目录，不下载到Git、不把回执全文发聊天。失败只清理本次新建的文件，原来源不写入；不要关闭原网页、换工作库或启用设备。

本机代码包放在仓库外 `outputs/management-initialization-2026-11-02-ready/`。它没有部署按钮，不会安装服务或自行连接SSH。
