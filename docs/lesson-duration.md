# 课程时长与下课时间

日期：2026-10-27。版本4.10.2-lesson-duration，安卓版本码77。

用户确认：目前“信息学奥赛提高班”每节120分钟，其他课程每节90分钟，之后可能调整。根据已验收备份共有6个提高班、37个其他班级。

## 使用

后台“班级 → 进入课程 → 展开班级 → 编辑班级 → 每节课时长”，可填写1至720的整数分钟，开课时间变化时自动更新预计下课时间。跨午夜显示“次日”。例如14:00开始的提高班默认16:00结束；16:30开始的其他班默认18:00结束。

未单独保存时长的旧班按明确保存的所属课程使用上述默认值；不从短班名、老师姓名或学生课时余额猜测。新建班级会跟随所选课程给出默认值，手动填写后不再因课程输入变化而覆盖。已有班级改所属课程时保留当前时长，需要不同时间时在同一编辑框调整。

当前规则即时用于班级时间展示，不在升级启动时批量改写旧班资料。只改课程分组或显示名、时长未变时保持原有业务资料；需要变更实际时长/开课时间时才保存相应字段和时间历史。修改时长不改变签到每次扣1课时的规则，不改已有签到、流水、请假或到课率分母。

## 历史与备份

时间历史按日期分段；同日再次编辑更新当日条目，以后的日期调整会保留之前日期的时间。确认前的历史时长不推测回填；没有历史时，当前默认值仅从2026-10-27起用于当前/未来预览，班级创建前也不推测时长。最多1000个时间历史段，达到上限后拒绝新增，避免保存无法通过恢复验证的备份。

历史记录、单班时长和结束时间随完整JSON备份保存；旧备份仍可恢复。校验时拒绝非法分钟、结束时间/跨日偏移不一致、日期倒置/重叠、历史末段与当前配置不一致。保存失败按现有事务整体回滚。已在服务器保存的课次不会因平板改时长而自动重排，需另行核对调整。
