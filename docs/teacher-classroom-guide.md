# 教师网页：课程与签到操作说明

网页入口：`http://47.97.226.219:18083`；机构：`weilai`；账号、密码沿用现有教师账号。

本说明对应“今日课程与历史签到”新版，已在真实服务器更新，并于2026年11月3日完成外网核验。刷新原网页并重新登录即可使用。

## 查看今天的课程

1. 登录；兼任教师和管理员的账号选择“教师”。只有教师身份的账号直接进入。
2. 默认显示“今日课程”，每个班是一张课程卡，显示上课时间及应到、已到、未到、请假人数。
3. 点击“查看 ××班 名单”，进入该节课的学生列表。
4. 点击“全部”“已签到”“未签到”“已请假”筛选；也可以输入姓名或学号，点“搜索学生”。
5. 点页面上方“刷新”重新读取状态；当前日期、班级及筛选条件保留。列表超过一页时点“继续加载”。

当天无课会明确提示，可改日期查询，不能因此判断学生资料丢失。教师只显示本人当前授权班级。

## 查看过去日期的签到

1. 进入“课程与签到”，修改“上课日期（北京时间）”，点“查看课程”。
2. 在课程卡上选择班级，逐人查看状态；接入前的签到还会显示原签到时间、方式，以及是否补签。
3. 接入前记录明确标为只读，不提供请假/补签按钮；显示的课时是接入前快照，不是该节课扣减后的历史余额。
4. 已删除班级或无法可靠对应教师权限的旧班记录，不按教师姓名猜测授权；管理员可在历史日期核对这些原记录。

当前切换边界为北京时间2026年11月3日。此前从封存的原网页明细读取，此后从新签到账本读取；查询不会再次扣课，也不会把旧记录当作新业务。

## 申请请假或补签

1. 打开接入后的对应课程名单，找到未签到学生。
2. 点“申请请假”或“申请补签”，填写原因，提交申请。
3. 补签仅在课程开始后提供；已签到、已请假或已有待审批申请的学生不能重复申请。
4. 在“请假与补签审批”查看进度。管理员或管辖范围内的考核专员审批通过后生效，再由平板接收结果。

请假保留在应到人数中，不作为实际签到，不扣课时。提交申请不是审批通过，审批通过也不等于平板已经保存；网页会分别显示进度。

## 更新范围

此版只改课程查询、历史逐人明细、筛选和网页提交兼容性，不修改学生资料、现有余额、账号或权限，不重新初始化数据库，不重新连接平板。管理员完整学生/班级/课时编辑仍在后续范围。
