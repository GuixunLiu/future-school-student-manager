# 教师网页：课程与签到操作说明

网页入口：`http://47.97.226.219:18083`；机构：`weilai`；账号、密码沿用现有教师账号。

本说明对应2026年11月3日已上线的历史补签/请假新版；平板已覆盖更新到4.12.3。刷新原网页并重新登录即可使用。

## 查看今天的课程

1. 登录；兼任教师和管理员的账号选择“教师”。只有教师身份的账号直接进入。
2. 默认显示“今日课程”，每个班是一张课程卡，显示上课时间及应到、已到、未到、请假人数。
3. 点击“查看 ××班 名单”，进入该节课的学生列表。
4. 点击“全部”“已签到”“未签到”“已请假”筛选；也可以输入姓名或学号，点“搜索学生”。
5. 点页面上方“刷新”重新读取状态；当前日期、班级及筛选条件保留。列表超过一页时点“继续加载”。

当天无课会明确提示，可改日期查询，不能因此判断学生资料丢失。教师只显示本人当前授权班级。

## 查看过去日期的签到

1. 进入“课程与签到”，修改“上课日期（北京时间）”，点“查看课程”。
2. 在课程卡上选择班级，逐人查看状态；接入前的签到还会显示原签到时间、方式，以及是否补签。
3. 找到“未签到”的应到学生，可点“申请请假”或“申请补签”。原始历史保留，审批后在名单显示更正结果和审批时间。已关联当前同步名册的学生显示当前剩余课时；未关联的记录仍显示接入前快照。
4. 已删除班级或无法可靠对应教师权限的旧班记录，不按教师姓名猜测授权；管理员可在历史日期核对这些原记录。

当前切换边界为北京时间2026年11月3日。此前从封存的原明细读取，批准更正后叠加结果；此后从新签到账本读取。查询不扣课，提交申请也不扣课。已归档、未关联或原时间不清楚的记录会显示需核对原因，不猜测学生身份或扣课。

## 申请请假或补签

1. 打开对应上课日期的课程名单，找到未签到学生；已存在的历史课堂也支持。
2. 点“申请请假”或“申请补签”，填写原因，提交申请。
3. 补签按钮在课程开始前不可点击，开课后可申请；已签到、已请假或已有待审批申请的学生不能重复申请。
4. 在“请假与补签审批”查看进度。管理员或管辖范围内的考核专员审批通过后生效，再由平板接收结果。

请假保留在应到人数中，不作为实际签到，不扣课时；补签批准后按一节课扣一次（2小时课程仍按本系统一节课的计费单位）。管理员在审批卡片核对“上课日期”和原因，点“批准”并填写审批意见。审批通过后网页会显示“等待平板接收”或“平板已保存”；平板需联网。重复接收不重复扣课。同日已有其他签到或请假的情况会阻止自动办理，需先核对。

历史周报保留原统计，并另列“历史更正记录”；当前课堂名单显示批准后的状态。不要把历史原统计和更正明细直接当作两个完整周报相加。

## 更新范围

本轮加入历史申请、审批、平板接收和去重保护，没有重建原账号或恢复旧数据库。尚未排出的历史课堂、已归档学生等需另行核对；本功能不是任意创建过去课程。管理员完整学生/课时编辑仍在后续范围。
