## 差异规则

| 情况 | 处理 |
| --- | --- |
| 一端签到，另一端缺记录 | 标明未镜像/另一端缺记录，不补签、不扣课、不重放历史 |
| 任一端有效请假与任一端签到冲突 | 单列冲突，保留两端事实，由负责人核对 |
| 网页请假未在平板出现 | 列出，不静默把网页事实写入平板 |
| 本机旧请假未在服务器出现 | 列出，不将启用前旧记录加入上传队列 |
| 双方各自登记请假且没有原回执关联 | 不因学生、姓名、时间或理由相似而合并 |
| 一端撤假、另一端仍有效 | 指明撤销未传达的方向，不自动取消另一端记录 |
| 多条有效请假、回执缺失或归属错误 | 停止自动匹配；跨学生引用直接拒绝 |
| 已确认回执但设备身份未知/不同 | 单列待核对，不认定是本设备已处理 |

请假始终保留在应到分母，不算实到、不扣课。核对工具不推导充值、续费或余额修复。
