# 平板迁移前离线核对

更新：2026-10-25。工具版本0.1.0。本阶段只核对，不执行导入、扣课、补签、联网或通知发送。日常App无需为此再次更新，服务器v0.4.0冻结发布包也未修改。

## 使用步骤

1. 平板后台进入“设置”，在“每日自动完整备份”点击“立即备份”，等待保存成功。正式App文件位于系统下载目录下的`未来学校学生管理系统/自动备份`。复制最新JSON到电脑，保留平板上的原文件。不要选择“恢复JSON备份”或清空资料。
2. 在电脑用Chrome打开交付目录`outputs/tablet-migration-review-v0.1.0/`中的`未来学校-迁移前核对-v0.1.0.html`，选择第①项平板JSON备份。无需启动服务器或安装软件。
3. 第②项“服务器核对清单”可以暂时留空；此时仅检查备份自身，不表示服务器已有相同资料。后续可用独立只读导出脚本生成完整的最小清单，与同学号的姓名、完整班级、余额及在读状态比较。
4. 查看错误与待确认项目，点击“保存核对报告”。报告保留学生姓名、学号、完整班级、余额及排课核对信息，应在校内保管；完整原备份可能含人脸，不需要发到聊天或上传服务器。
5. “清空本页”清除当前页面的文件引用和结果；不删除原文件或已下载报告。页面不使用浏览器本地存储，关闭后重新选择文件。

## 核对范围

保留学号前导零；不同学号的同名学生保持独立。检查学生和班级编号、重复学号/完整班名、当前班级关联、课时精度、长期不来状态、隔周首课日与星期、日期历史的顺序和重叠、签到与流水关联、有效请假与同日签到冲突。负课时保留，不自动归零；老师标签不用于创建账号或授予权限。

报告采用字段白名单，不导出人脸、照片、联系方式、密码、设备凭证、请假原因或其他未知字段。原文件只在当前页面内存读取，不修改。页面内容安全策略禁止网络连接和外部脚本；文件内容以文本显示。

工具不展开调课/加课为实际课次，只统计其数量并要求人工核对。不完整验证历史班级归属或还原缺失历史，不从当前余额反推续费/新生，不补传原有签到或请假。长期不来学生、历史转班、老师真实身份和服务器课次须单独制定迁移方案。即使无错误，`ready_for_import`始终为false。

单文件上限128MiB，最多10000班级/学生，签到、流水、请假和各类安排分别最多200000条，单对象日期历史最多1000段。页面预览前200名学生及前200个班级，报告包含全部核对行；问题明细最多2000条并显示截断提示，分类总数仍完整。超限文件停止核对，不能把局部结果当成完整结果。

服务器比较只接受标识为`wxnotify-roster-review`、schema_version=1、complete=true的完整清单，需手工确认机构和时效。不是账户登录或身份认证；仅服务器存在的学生不会自动删除，冲突不会覆盖。

## 服务器最小清单工具

源码为`server/ops/export-roster-review.py`，交付副本`export-roster-review-v0.1.0.py`及独立校验文件。当前仅准备并测试，尚未上传或在真实服务器运行。

后续使用普通部署账号，显式指定私有数据库、机构标识及全新的私有输出路径。脚本检查路径、数据库标识/完整性/关联，使用只读连接和一致性读事务，按机构导出班级、教师显示名/编号和学生必要字段；输出0600、拒绝覆盖，不导出账号密码、会话或审计记录。结果仍含学生资料，不能公开发布。只读表示脚本不修改业务资料，不表示可阻止运行中的业务同时更新数据库。Linux路径/权限检查尚未在真实服务器验收；Windows专项测试模拟该检查，未接触真实数据库。
