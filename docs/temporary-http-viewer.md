## 实现

- `server/ops/temporary-http-viewer.py`：Python标准库HTTP代理，单独18083端口，后端固定宿主机回环18082。每次访问须满足精确Host和Origin边界，再重建内部Host，只有必要的Authorization头传入后端；不信任用户转发身份头，不直接打开数据库、不记录请求/凭证。
- 只有`/v1/auth/login`和`/v1/auth/logout`允许POST，其余仅GET/HEAD；原后台权限和只读守卫继续有效。教师不能跨班，管理员归档等读权限依原账号。正文16KiB、响应4MiB、8个并发工作线程、10秒连接/后端超时，登录另有来源频率限制，响应no-store。后端不健康或不再只读时拒绝代理，不能因后端改成可写而继续暴露。
- 页面标记“临时HTTP查看 · 名册/余额快照 · 平板尚未实时同步”。有效期从实际部署起14天，超过后拒绝访问，续期需再次核对条件；不自动无限延期。
- `server/ops/install-http-viewer.py`：仅在新的`/opt/wxnotify/app/http-viewer-*`私有目录写两份代码，普通部署账号注册独立`wxnotify-http-viewer.service`。固定核对原27项发布源码、旧服务状态和只读健康，拒绝已有新单位或端口。启用失败只停/禁用自己创建的新增单位，保留现场，不动原服务/站点。
- `server/ops/deploy-http-viewer.cjs`：固定两份输入哈希、一次SSH标准输入传输，无密码参数和数据库上传。成功回执先落盘，再从电脑探测外网`/viewer/health`，核对源码指纹与期限。服务器本机成功、外网可达、教师实际登录是三个不同的验收结果。

不调用sudo、不修改Nginx/80/443/18081/18082、不开放云安全组或防火墙，也不改冻结后台源码。服务通过用户级systemd常驻，配置256MiB/50%CPU/32任务限制，实际Linux内核执行限制仍需另验。

## 执行与暂停

仓库外入口：`outputs/temporary-http-viewer-2026-10-28-ready/DEPLOY-HTTP-VIEWER.cmd`，ASCII/CRLF；该目录的私有计划含实际服务器和本机路径，不入Git。负责人运行一次并在SSH提示输入服务器密码，教师不使用部署脚本。

实际执行后检查本机回执`outputs/private-http-viewer-2026-10-28/http-viewer-deployed-*.json`：

1. 必须有local_ready、原服务/源码保持及独立服务active/running/enabled的证据，不能只因上传结束就宣称已部署。
2. `external_access_verified`为false时，不重跑部署。先核对TCP18083的云安全组/防火墙放行；如有范围要求，可以限定为测试教师的来源地址。不猜测公网入口已正常。
3. 外网可达后，再实际核验现有账号登录、教师仅本班、管理员范围、业务写入拒绝及显示非实时快照。未完成不得标记教师网页登录验收通过。

暂停只执行：

```sh
systemctl --user disable --now wxnotify-http-viewer.service
```

该命令只停新增HTTP入口，原核对网页、账号和数据库继续保留。不要删除数据库、恢复旧平板备份、重复签到或修改账号来排查网络入口。
