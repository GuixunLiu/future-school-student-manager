- `server/ops/temporary-http-viewer.py`：Python标准库HTTP代理，单独18083端口，后端固定宿主机回环18082。每次访问须满足精确Host和Origin边界，再重建内部Host，只有必要的Authorization头传入后端；不信任用户转发身份头，不直接打开数据库、不记录请求/凭证。
