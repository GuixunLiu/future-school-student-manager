# 今日课程与历史逐人签到：接续记录

## 本轮问题与结果

用户发现教师看不到学生签到入口。旧版默认“考核材料”，按日查询又只读接入后的规范课次；因此选择10月31日、11月1日等历史日期时，虽然原记录保留，却没有逐人入口。

现已实现：教师选择工作身份后默认今日课程；“课程与签到”按日期显示课程卡与完整应到/已到/未到/请假计数，点击班级查看名单，按状态或姓名/学号筛选。刷新保留当前日期、班级和过滤，不跳回今天。旧日期在同一接口展示封存明细及原签到时间/方式，标记只读和快照余额，不制造缺失历史、不重扣课。教师范围由当前班级ID授权核对，不按同名教师或旧班名称猜测。

同时修复公网HTTP下 `crypto.randomUUID` 可能不可用导致提交申请失败的问题；采用 `crypto.getRandomValues` 生成同内容重试复用的请求编号，不改变现有审批幂等/权限检查。
